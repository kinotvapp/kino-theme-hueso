# Hueso

Blanco hueso liso, marrón de tinta y terracota: un tema claro y cálido, sin blanco puro.

Tema para [Kino](https://github.com/kinotvapp/kino-light). Cambia los colores y las formas de toda la app, trae una pantalla de presentación y no se conecta a internet.

En Kino, escribe `kinotvapp/kino-theme-hueso` en **Plugins ▸ Agregar un plugin**. Después ábrelo y pulsa **Activar**.

Necesita Kino 0.9.81 o superior.
